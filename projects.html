FINTECH · BOND RISK ANALYSIS

Rate My Bond

A full-stack bond risk-analysis platform for Indian retail investors, centered around transparent credit and return calculations.

Analysis engine

Implemented a custom credit-scoring engine covering Probability of Default (PD), Loss Given Default (LGD), Expected Loss and risk-adjusted return.

Designed a config-driven issuer-strength model across seven financial metrics: ICR, leverage, cashflow quality, refinancing risk, sector, group support and event risk.

Platform engineering

Built a production REST API with validation, rate limiting, CORS and centralized error handling.

Implemented Firebase-authenticated protected routes and MongoDB issuer/analysis data pipelines with CSV ingestion.
