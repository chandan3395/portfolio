# Chandan G — Static Portfolio

A responsive portfolio built with **HTML, CSS and vanilla JavaScript only**.

## Files

- `index.html` — main portfolio
- `projects.html` — detailed projects
- `resume.html` — resume summary and PDF links
- `style.css` — shared design system and responsive layout
- `script.js` — theme, mobile menu, scroll reveals and small interactions
- `resume.pdf` — supplied resume

## Run locally

No Node.js or package installation is required.

### Option 1 — open directly

Open `index.html` in a browser.

### Option 2 — local server (recommended)

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

## Host

This is a static site and can be hosted on GitHub Pages, Vercel, Netlify, Render static hosting, or any web server that serves HTML/CSS/JS files.

## Notes

The resume PDF included here is the supplied source document. Direct repository/live-demo URLs were not present in the supplied resume; the verified GitHub profile is linked instead of inventing project URLs.
